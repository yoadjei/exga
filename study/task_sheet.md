# Task instructions

*Read aloud by the researcher before training and before each task.*

## The task

You will look at a few research papers and, for each paper, find the value of a short list
of items ("fields"), such as the number of participants or the country where the data were
collected. Each field has a question that says exactly what to look for.

- Write numbers as they are printed in the paper, without units.
- If a paper does not report a field, write **NR**.
- Give one answer per field.
- Work as carefully as you would for a real review: being right matters as much as being
  quick.

You will do this twice, on two different sets of papers: once by hand and once with a tool
called exga. Each time you have up to 25 minutes. Say "done" when you have finished. It is
fine not to finish; leave the rest blank.

## By hand

You have the papers as PDFs and a sheet with one row per paper and field. Read the question
in each row, find the answer in the paper, and type it in the **value** column.

## With exga

exga has already read the papers and proposed a value for every field. On the **Review**
page, each value has a status:

- **✓ Accepted**: exga's error check says values like this one are wrong rarely enough to
  use without checking.
- **! Check**: exga cannot vouch for this value; please check it.
- **— Not certifiable**: this field could not be checked statistically; please check it.

Select a row to see where in the paper the value came from, with the passage highlighted.
If a value is wrong, type the right one under **Correct value** (or tick **The paper does
not report this**) and press **Save correction**. If it is right, you do not need to do
anything. You may check any value, including accepted ones.

When you are done, open the **Export** page and press **Download results.csv**.
